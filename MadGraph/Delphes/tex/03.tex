\section{Configuración en el modelo HAHM}
    \subsection{Tarjeta run\_card.dat}
    La tarjeta \textit{run\_card.dat} generado para el modelo de HAHM elimina las siguientes variables
    \begin{itemize}
        \item \textbf{Minimum and Maximum pt's (for max, -1 means no cut)}: ptl, ptlmax.
        \item \textbf{Maximum and minimum absolute rapidity (for max, -1 means no cut)}: etal, etalmin.
        \item \textbf{Minimum and maximum DeltaR distance}: drll, drllmax.
        \item \textbf{Minimum and maximum invariant mass for pairs}: mmll, mmllmax.
        \item \textbf{Minimum amd maximum invariant mass for all leptons}: mmnl, mmnlmax.
        \item \textbf{Minimum and maximum pt for 4-momenta sum of leptons / neurino for pair of lepton includes only same flavor, opposite charge}: ptllmin, ptllmax.
        \item \textbf{Inclusive cuts}: xptl.
        \item \textbf{Control the pt's of leptons sorted by pt}: ptl1min, ptl2min, ptl1max, ptl2max. 
    \end{itemize}
    además de agregar la siguiente variable
    \begin{itemize}
        \item \textbf{Inclusive cuts}: ptheavy
    \end{itemize}
